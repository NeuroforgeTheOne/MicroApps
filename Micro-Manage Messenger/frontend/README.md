# Micro-Manage Messenger Web Client

## Overview
Web/PWA client for Micro-Manage Messenger. Supports:
- Real-time chat (Socket.IO)
- Media uploads
- Group and 1:1 chat
- Emojis, reactions, typing/read indicators
- Dark mode, glassmorphism

## LAN Setup
- Set backend URL to your server's LAN IP (e.g., `http://192.168.1.10:5000`)
- Run with Docker or `npm install && npm run dev`

## Cloud Setup
- Set backend URL to your public server address
